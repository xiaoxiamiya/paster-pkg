# Paster 使用说明

Paster 是放在菜单栏里的剪贴板历史。复制过的文字、图片、链接和文件会留在底部的卡片面板里，选中一张就能贴回刚才的窗口。

它不出现在程序坞。安装或打开之后，看屏幕顶部菜单栏里的剪贴板图标。

## 安装

安装包在仓库的 Releases。仓库同时发布在 GitHub 和 Gitee，两个站点各有自己的地址，请按你正在看的站点选用。

- GitHub：[Releases](https://github.com/xiaoxiamiya/paster-pkg/releases)
- Gitee：[Releases](https://gitee.com/gao-haoliang/paster-pkg/releases)

下载后双击，按向导安装。Paster 会被放到「应用程序」，不会自动打开，也不会出现在程序坞。

从启动台或「应用程序」打开它，再按 **⇧⌘V** 唤起底部卡片面板。

## 打开和关闭

默认快捷键是 **⇧⌘V**。在任意应用里按下，面板从屏幕底部升起；再按一次就收起。快捷键可以在设置里改成别的组合，至少要带上 ⌘、⇧、⌥、⌃ 里的一个。

也可以直接点菜单栏图标。点一下打开，再点一下关闭。

**Esc** 关闭面板。

面板跟着鼠标所在的那块屏幕，贴在底部，宽度和屏幕一样。高度、字号可以在设置里调。

## 粘贴一张卡片

面板打开后，左右方向键移动高亮。选中的方式有三种：

| 操作 | 结果 |
| --- | --- |
| **Enter**，或点击卡片 | 写回剪贴板，贴到原来的窗口，然后关闭面板 |
| **⌥Enter** | 只贴纯文本。链接和富文本会去掉格式 |
| **⌘1** 到 **⌘9** | 从当前高亮的卡片往右数。⌘1 是高亮的那张，⌘2 是它右边一张，按下后立刻粘贴并关闭 |

要自动粘贴，需要允许 Paster 控制电脑：

> 系统设置 → 隐私与安全性 → 辅助功能 → 打开 Paster

还没允许时，选中卡片仍然会把内容放进剪贴板，只是不会替你按下 ⌘V。允许之后再试一次即可。

右键卡片里的「复制」只放进剪贴板，不自动粘贴。适合想自己决定贴到哪里的时候。

## 查找

按 **↑** 进入搜索栏，输入关键字。会查「全部」和每个标签里的卡片，标题和正文都算，不区分大小写。当前分组里的匹配排在前面。

搜完按 **↓** 回到卡片。搜索栏是空的时候，按 **→** 可以改去切换分组。

没有匹配时，面板会写「无匹配结果」。清空搜索框就回到原来的列表。

## 分组

顶部从左到右是：

1. **全部** — 还没归类的记录
2. **ReadMe** — 内置说明，可以右键删除
3. 你自己建的标签，右边的 **+** 用来新建

左右方向键可以在这些分组之间移动，**Enter** 进入当前分组的卡片。

把卡片拖到某个标签上，它就归到那里。也可以右键卡片，选「移动到标签」。

| | 全部 | 自己的标签 |
| --- | --- | --- |
| 保存多久 | 按设置的天数自动清理，默认 7 天 | 一直留着 |
| 数量 | 最多约 2000 条，更早的会被挤掉 | 不按这个上限删 |
| 顺序 | 可以拖动调整 | 可以拖动调整 |

标签适合留下次还要用的文字和链接。密码、验证码用完即可，不必拖进标签：标签会一直留着，「全部」则会按存储天数清掉。

自己的标签可以左右换位。把一个胶囊拖到另一个胶囊上，两边会让开位置，松手后停在那里。拖动时不会出现加号。也可以右键胶囊，选「左移」或「右移」，一次移动一格。最右边的标签不能再右移。

标签名字可以右键修改。右键还可以换胶囊颜色、清空或删除。删掉标签时，里面的记录会回到「全部」。

## 卡片上能做什么

右键一张卡片，常用的有：

- **设置标题**。写在卡片底部，和时间同一行。已经有标题时，菜单里是 **重命名标题** 和 **清除标题**
- **复制** / **复制为纯文本**
- **预览**，快捷键是空格。文字会打开快速查看；整段都是网址时，空格直接用浏览器打开
- **翻译**。在 macOS 15 及以上使用系统翻译，文字留在本机，不上传。语言包没装时，会交给系统的下载界面
- **工具**。转换结果会变成一张新卡片，插在同一分组最前面，原来的那张还在
- **移动到标签**
- **删除**，快捷键是 **⌘⌫**

工具包括：JSON 格式化和压缩、时间戳、时区、Base64、驼峰和蛇形、URL 编解码、Unicode 转中文、Cron 解析、字数统计、cURL 转 Python / Go / Java / JavaScript。用不上的项目不会出现。文本对比单独写在下面。

图片、文件、链接卡片没有文字工具。文件可以在 Finder 里打开。正文里夹着的网址可以单独点开，整段都是一条网址时，卡片本身就是链接。

多选：**⌘A** 全选当前分组里显示出来的卡片，**⇧⌘←** / **⇧⌘→** 向左右加选。多选时可以一起拖进标签，或一起删除。

## 标题

右键卡片，选 **设置标题**。标题出现在卡片底部左侧，稍粗一点；时间移到同一行的右侧。还没写标题时，时间仍靠左。

最多 **16** 个字，中英文都按 1 个字计。再往下打会自动截掉。放不下的字以省略号收起，鼠标停在标题上可以看到全文。

**回车**保存。点到输入框外面也会保存。把内容清空后回车，标题就去掉了，和右键 **清除标题** 一样。**Esc** 放弃这次修改，面板保持打开。改标题时，左右方向键只在标题文字里移动。

搜索会匹配标题。导出的 JSON 里也有标题，换电脑导入后还在。

## 文本对比

用来看两段文字差在哪里。只对文字卡片有效，图片、文件和链接不能比。

1. 用方向键把高亮停在其中一张文字卡片上。
2. 按住 **⇧⌘**，再按 **←** 或 **→**，把紧挨着的那张也选上。必须正好两张，而且都是文字。列表里靠左的是「左」，靠右的是「右」。
3. 右键其中一张，选 **文本对比**。只选中一张，或选中的不是文字时，这一项是灰的。

两段完全一样时，面板底部只提示一句，不会多出卡片。

有差别时，原来的两张留在原地。同一分组最前面会插入一张新卡片，写明有几处不同：

- 某一行被改掉：标出旧的和新的
- 左边有、右边没有：按删除列出
- 右边多出来的：按新增列出

卡片里，删除的词是红色，新增的词是绿色。对比结果太长时，只展开前面的几处，并注明后面还有。

## 设置

右键菜单栏图标，选「设置」。改动会马上生效。

| 项目 | 作用 |
| --- | --- |
| 存储时长 | 只影响「全部」。1 到 90 天 |
| 清除记录 | 手动删掉「全部」里早于所选天数的记录。标签里的不会动 |
| 导入 / 导出 | 用 JSON 备份全部标签和记录。导入时跳过已经有的相同记录，不覆盖现有内容 |
| 系统语言包 | 查看简体中文和英文语言包是否已安装。初次安装不会下载语言包 |
| 外观 | 跟随系统、浅色或深色。初次安装为深色 |
| 主题色 | 按钮、选中的标签，以及卡片高亮边框。初次安装为 #68BC7D |
| 面板高度 | 底部面板有多高。初次安装为 380 px |
| 字体尺寸 | 界面文字缩放。初次安装为 150% |
| 滚轮灵敏度 | 卡片横向滚动的快慢。初次安装为 4.0x |
| 唤起面板 | 改全局快捷键。初次安装为 ⇧⌘V |
| 恢复初始设置 | 把上面这些设置回到初次安装的值。不改变系统语言包。未分类里早于 7 天的记录会按存储时长清理 |

导出的备份包含标签、卡片标题，以及文字和图片。换一台 Mac 时，可以先导出，再在新机器上导入。

## 快捷键

面板已经打开、并且焦点在卡片上时：

| 按键 | 作用 |
| --- | --- |
| ⇧⌘V | 打开或关闭面板。这是默认组合，以你在设置里保存的为准 |
| Esc | 关闭面板。正在改标题时，改为放弃这次修改 |
| ← → | 上一张 / 下一张 |
| ⌘← | 回到最左边 |
| ↑ | 进入搜索；在搜索栏再按 ↑ 会离开搜索 |
| ⌘↑ | 去切换顶部的分组 |
| ↓ | 从搜索或分组回到卡片 |
| Enter | 粘贴并关闭 |
| ⌥Enter | 只贴纯文本 |
| ⌘1–⌘9 | 从高亮卡片往右快捷粘贴 |
| 空格 | 预览；纯链接则在浏览器打开 |
| ⌘A | 全选当前列表 |
| ⇧⌘← / ⇧⌘→ | 向左 / 向右加选。正好两张文字时，可右键「文本对比」 |
| ⌘⌫ | 删除选中的卡片 |

分组高亮时，**← →** 换分组，**Enter** 进入该分组的卡片。

## 安全性

Paster 自己不访问网络。没有账号，没有云同步，后台也不会检查更新或上报使用情况。复制下来的文字、图片、链接和文件只留在这台 Mac 上。

记录、标签、卡片标题、较长的正文和图片都在：

```text
~/Library/Application Support/Paster
```

面板高度、主题、快捷键写在本机偏好里，同样不离开这台电脑。换机器时，在设置里导出 JSON，再到另一台 Mac 上导入。

这些是本机上的普通文件，Paster 不会再加密一层。平时只有这台电脑上的程序读得到。万一机器里有恶意软件，它也可能读到剪贴记录。重要密码放在钥匙串或密码管理器里更合适，不必收进会长期保留的标签；若已经复制过，从「全部」里删掉即可。

翻译用的是 macOS 15 及以上的系统翻译，文字在本机处理，不会上传。语言包还没装时，交给系统的下载界面，由系统去取。

卡片里的网址，只有你点开、或对整段都是链接的卡片按空格时，才会交给默认浏览器。之后的访问记在浏览器上。

想自己确认，用活动监视器看 Paster 有没有流量：

1. 打开「活动监视器」。Spotlight 里搜这个名字即可，它在「应用程序 → 实用工具」里。
2. 点窗口顶部的 **网络**。
3. 在进程列表里找到 **Paster**。
4. 看「已发送字节」和「已接收字节」。

打开面板、搜索、粘贴、翻译时，这两列保持为 0。点开链接之后，增加的是浏览器那一行，不是 Paster。

## 常见问题

**Q1: 装完没有窗口，程序坞里也没有 Paster。**

它是菜单栏应用。安装包只完成安装，不会自动打开。从「应用程序」打开 Paster 后，看屏幕顶部的剪贴板图标。按 ⇧⌘V，或点一下菜单栏图标，底部面板才会出现。

**Q2: 选中了卡片，原来的窗口没有贴上。**

先看辅助功能里有没有允许 Paster。允许之后再选一次。如果只是想把内容放进剪贴板，用右键「复制」，然后自己按 ⌘V。

**Q3: 「全部」里的记录过几天不见了。**

这是存储时长在起作用，默认保留 7 天。想留下的内容，拖进一个自己的标签。标签里的记录不会按天数删除。

**Q4: 搜索找不到某条记录。**

搜索会查全部和各个标签里的标题、正文。还是没有的话，这条可能已经按「全部」的存储时长清掉了。

**Q5: 换了电脑，历史还在吗？**

剪贴记录保存在本机。在设置里导出 JSON，到新电脑上导入。卡片标题会一起带走。已经存在的相同记录会跳过，不会覆盖。
